# Agent Tools 0.7 „Clearpath“

Zwei Ziele: das vorhandene Richter-Routing gegen kleine riskante Änderungen absichern und die tatsächliche Cache-Nutzung messbar machen. Keine allgemeine Modellkaskade, kein neuer API-Proxy und keine Provider-Kostenannahmen.

## Routing

Ab 300 geänderten Diff-Zeilen sowie bei Vertrags-/Format-/Migrationspfaden wird Sol mit hohem Denkaufwand gewählt. Auch Prüf-/Paket-/Schema-/Sperrinfrastruktur geht an Sol. In CE liest der Richter zusätzlich `Tools/test_map.json`: Pfade mit `core: true` oder `core: "merge"` gelten unabhängig von der Diffgröße als riskant. Bekannte Spielstand-/Einstellungspfade bleiben ohne Testkarte abgesichert; neue, entfernte oder umbenannte Pfade in möglichen Kernbereichen werden vorsichtig hochgestuft. Eine ungültige Karte macht solche Codeänderungen nicht zu Routine.

Kleine Doku- und gewöhnliche Featureänderungen bleiben bei Luna mit mittlerem Denkaufwand. Die CLI nennt Auswahl und Grund; eine bewusste `--model`-Wahl bleibt erhalten und zeigt die automatische Gegenempfehlung. Die Regeln erfassen Pfad-/Metadatenrisiko, keine inhaltliche Fehlerwahrscheinlichkeit. Das ist eine Verbesserung des bestehenden Richters und steuert keine fremden Clients oder laufenden Claude-/Gemini-Sitzungen.

## Cache-Messung

`./ce report <Claude-Transcript> --json` ergänzt ein `usage`-Objekt. Anthropic meldet drei disjunkte Inputzähler: `input_tokens` (frisch), `cache_creation_input_tokens` und `cache_read_input_tokens`. Ihre Summe ergibt den beobachteten Input je Anfrage; Output wird getrennt gezählt. Streaming-Updates derselben Nachrichten-ID zählen komponentenweise mit dem höchsten Zähler einmal. Synthetische/Nicht-Assistant-Records und ungültige Zahlen ergeben keine Messwerte.

Eine Inputsumme und die Cache-Lesequote werden nur für vollständig gemessene Anfragen berechnet. Messabdeckung, durchschnittlicher und maximaler Input machen Lücken und große Anfragen sichtbar; fehlende Usage bedeutet weder null Tokens noch null Prozent Treffer. Die Auswertung erfolgt je Transcript und Zeitfilter. IDs können sich zwischen Dateien wiederholen: Dateiergebnisse sind keine global deduplizierte Abrechnung. Die Anthropic-Formel wird nicht auf OpenAI-/Gemini-Zähler übertragen.

Cache-Lesen kann günstiger sein als erneutes Verarbeiten; es verkleinert den Kontext nicht. Keine Preisberechnung, kein Guthabenabruf und keine bezahlten API-Aufrufe. Gezielte lokale Tests prüfen positive/negative Routingfälle, Streaming, Teilmessungen, ungültige Zahlen, synthetische Daten, Zeitfilter und bestehende Antigravity-Transcripts. Abnahme und genaue Testergebnisse stehen in der PR-Beschreibung.
