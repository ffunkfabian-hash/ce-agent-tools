Transkript (`~/Library/Caches/CubeEscape/earshot-20261104/auszug.md`): jedes `additionalContext` steht als `hook_additional_context` vor dem Modell, das alle drei Codes nannte; `systemMessage` landet nur als `hook_system_message` (Oberfläche). **Stop ist anders:** Auf ein Stop-`additionalContext` antwortet das Modell noch einmal, und ein Hook, der bei jedem Stop wieder Kontext liefert, läuft in eine Schleife (10 Stop-Aufrufe in der Probe, bis Claude Code abbrach). ## Grenzen

- Die Probe lief headless (`claude -p`, Haiku 5.5, Claude Code 2.1.310) mit `--settings`-Hooks; die interaktive Oberfläche rendert dieselben Transkript-Einträge, wurde aber nicht gesondert geprüft.
- Ein Stop-`additionalContext` kostet eine Antwortrunde; darum nur `check-before-stop`, einmal je Sitzung. Die übrigen Stop-Hinweise (`ce_report.hints`) stehen in `report.md` und erreichen das Modell nicht – gewollt, sie waren Messung, keine Handlungsanweisung.
- `pulse` zählt Transkriptzeilen mit `"type": "user"`/`"assistant"` (wie `ce_report`); ein Transkript-Dump im Werkzeugergebnis könnte mitzählen. Der Input-Wert ist das letzte `usage`-Objekt im Dateiende (512 KB), kein Maximum über die Sitzung.
- `rule_text` kopiert Kommentare als Text (`# git push --force` trifft weiter – ein Block mehr, nie einer weniger) und blendet einzeilige Zitate nur bei den Textprogrammen aus; `bash -c '…'`, Shell-Heredocs und `$(…)` in Zitaten bleiben lesbar und werden geprüft. Wrapper erkennt es nur aus einer festen Liste (`env`, `sudo`, `timeout` …); ein unbekannter Wrapper vor `bash <<EOF` macht den Heredoc zu Datentext. Here-Strings (`<<<`) gelten nicht als Heredoc; ein Python-Heredoc, der `subprocess` aufruft, ist Datentext (Trimline-Fall, gewollt). `expansions()` liest `$(…)` mit Klammerzählung (Zitate übersprungen) und Backticks; `((…))` wird nur am Wortanfang erkannt. `line_runs_shell` kennt Shells und Wrapper nur aus festen Listen; ein Heredoc an ein unbekanntes Programm, das selbst eine Shell startet (`xargs` ist in der Liste, `make` nicht), bleibt Datentext.
- Die Drossel liegt in einer Datei je Sitzung (`heavy_lock.cache_dir("hooks")`, 14 Tage); zwei Hooks desselben Aufrufs schreiben verschiedene Schlüssel, ein verlorener Zähler bedeutet höchstens einen Hinweis mehr.
- `lessons_imported` erkennt nur `@`-Importe am Zeilenanfang bis eine Ebene tief, relativ zur importierenden Datei; andere Formen laden die Datei weiter.
- Versionsbericht als `docs/versions/0.33.md` (Repo-Konvention und `ce_lint`), nicht als Abschnitt in `0.md`.
