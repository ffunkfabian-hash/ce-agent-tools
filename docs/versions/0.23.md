# Agent Tools 0.23 „Modelline“

Stand: umgesetzt, nicht committet. Basis: 0.22.0 (`9f1ed12`). Sitzung: Sonnet 5.5 medium, Branch `claude/ce-agent-tools-modellzeile-c601d0`.

## Anlass

Postfach cubeescape-nexogen#16: „Modell und Aufwand: nicht angegeben“ in Meldungen von Sitzungen, deren Anmeldung die Modellzeile hatte
(CE 0.115: 6381163316 vs. 6381261710; TG 0.26: 6372927058 vs. 6373473967; TG-Patches 6368742151, 6372459367).

## Ursachen (reproduziert in `tests/test_postfach_modelline.py`)

1. `say` las das Modell nur über `am.reservation`, und die liefert nach `RESERVATION_DAYS` (3) nichts mehr – auch nicht das Modell.
   Lange Sitzungen verlieren die Modellzeile nach drei Tagen. Test rot ohne Korrektur.
2. Eine Reservierung durch eine ältere eingebettete Kopie (vor 0.21) speichert kein Modell; die Anmeldung trug es trotzdem.
3. `remember` schrieb die Datei ohne Modell neu, wenn derselbe Name ohne `--model` erneut gespeichert wurde.

## Korrektur

`ce_postfach.own_model(repo, sender)`: frische Reservierung → Sitzungsdatei gleichen Namens ohne Altersgrenze → eigene Anmeldung im
Postfach (`announced_model`, 30 Tage, nur bei GitHub-Origin, Fehler → leer) → sonst Hinweis wie bisher. Nie eine zweite Modellzeile.
`ce_session_name.remember` übernimmt Modell/Auftrag der früheren Datei gleichen Namens.

## Nicht behoben

Eine eingebettete Kopie ohne Plugin-Stand 0.23 bleibt beim alten Verhalten, bis sie nachzieht.
