# 0.42.0 „Ratchet“ – ./ce pin, Pin-Runden ohne Sitzung je Repo

Sitzung `CE-AGENT-TOOLS 0.42 „Ratchet“ · Mac` (Claude Opus 5.5, high). Basis `main` 2a3af6d (0.41.1).

**Ergebnis:** `./ce pin <version>` zieht den Werkzeug-Pin in allen aktiven Repos nach und meldet je Repo eine Tabellenzeile mit dem Stand von `./ce merge-check`. Es legt PRs an und mergt nicht. Es verlangt `version` als `{file, pattern}`: Motiongen und Critic bekommen das mit [PR 72](https://github.com/ffunkfabian-hash/cubeescape-motiongen/pull/72) und [PR 32](https://github.com/ffunkfabian-hash/cubeescape-critic/pull/32), bis dahin stoppen sie im Werkzeug.

**Lehren:** `status` in `repos.json` ist Freitext, nur `stillgelegt` schließt aus. `gh` im Textmodus macht aus CRLF LF, darum liest das Werkzeug Bytes. Stufe 1 hängt am Ordner: `merge-check` muss aus der Kopie laufen, deren Head der PR-Head ist.
