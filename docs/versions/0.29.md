# 0.29.0 „Plumbline“ – robuster Push-Sperrtest für `./ce vibe`

Fertig – Testkorrektur ohne Werkzeugänderung. Sitzung Sightline · Cloud, 31.10.2026.

## Anlass

`tests/test_vibe.py › test_worker_cannot_push_and_has_no_gh_login` war in der Cloud rot (1 von 662): Der Container setzt selbst
`GIT_CONFIG_COUNT=3`. `ce_vibe.worker_env()` hängt die Push-Sperre (`remote.origin.pushurl`) richtig an Stelle `GIT_CONFIG_COUNT`
an, der Test erwartete sie fest an Stelle 0. Auf dem Mac (ohne vorab gesetzte Einträge) war er grün.

## Änderung

- Fake-Vibe zeichnet alle `GIT_CONFIG_KEY_*`/`GIT_CONFIG_VALUE_*` auf statt nur Stelle 0.
- Der bestehende Test sucht die Sperre an Stelle `GIT_CONFIG_COUNT-1`.
- Neuer Test `test_worker_cannot_push_with_pre_existing_git_config`: zwei vorab gesetzte Einträge bleiben unverändert, die Sperre steht
  an Stelle 2, `GIT_CONFIG_COUNT` ist 3 (Umgebung per `mock.patch.dict`).
