# 0.36.0 „Capstan“ – Kern über SessionStart, Nachtlauf-Abbruch als Warnung

Sitzung `CE-AGENT-TOOLS 0.36 „Capstan“ · Mac` (Claude Opus 5.5, high). Trimline 29 und 1b, Basis `main` 0bfb2ac.

**Ergebnis:** Eine Sitzung ohne globale `CLAUDE.md` bekommt die zehn Regeln des harten Kerns wortgleich an den Anfang ihres Startkontexts, eine Sitzung mit geladenen Regeln nicht noch einmal. Der Nachtlauf testet ein Repo trotz falschem Branch oder geändertem Checkout, wenn dessen `nightly.sh` belegbar auf origin/main in einem eigenen Worktree arbeitet, und meldet das als Warnung; alles andere bleibt `red (checkout)`.

**Lehren:** Ein Dateiname ist kein Beleg: Drei Repos haben ein `nightly.sh`, nur eines arbeitet auf origin/main. Eine Ausnahme von einer Schutzregel prüft, was wirklich startet, nicht was im Auftrag steht. Ein zurückliegender `main` ist kein fremder Stand, darum zählt der gemeinsame Commit mit origin/main.

**Grenzen:** Ein Cloud-Container ohne Plugin bekommt den Kern nicht. Der Wortvergleich mit der Quelle läuft nur mit Nexogen-Checkout, also am Mac, nicht in der CI.
