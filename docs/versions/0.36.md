# 0.36.0 „Capstan“ – Kern über SessionStart, Nachtlauf-Abbruch als Warnung

Sitzung `CE-AGENT-TOOLS 0.36 „Capstan“ · Mac` (Claude Opus 5.5, high). Trimline 29 und 1b, Basis `main` 0bfb2ac.

**Ergebnis:** Eine Sitzung ohne globale `CLAUDE.md` bekommt die zehn Regeln des harten Kerns wortgleich an den Anfang ihres Startkontexts, eine Sitzung mit wortgleich geladenen Regeln nicht noch einmal; auch ein Fehler in einem anderen Teil des Startkontexts kostet den Kern nicht. Der Nachtlauf testet ein Repo trotz falschem Branch oder geändertem Checkout, wenn dessen `nightly.sh` belegbar auf origin/main in einem eigenen Worktree arbeitet, und meldet das als Warnung; alles andere bleibt `red (checkout)`. An den heutigen Checkouts ändert das noch nichts: Der `main` von Cube Escape trägt die alte Skriptfassung und bleibt rot, bis er nachgezogen ist. Client-Stand: Hook als Prozess mit nachgebauter Eingabe geprüft, Probe im echten Client und in der Cloud nicht geprüft.

**Lehren:** Ein Dateiname ist kein Beleg: Drei Repos haben ein `nightly.sh`, nur eines arbeitet auf origin/main. Eine Ausnahme von einer Schutzregel prüft die Fassung, die wirklich startet, nicht die neueste. Was jede Sitzung erreichen soll, darf nicht am Rest derselben Ausgabe hängen.
