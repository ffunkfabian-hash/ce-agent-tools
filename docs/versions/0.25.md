# Agent Tools 0.25 „Spyglass“

Stand: umgesetzt. Basis: 0.24.0 (`f8a13fc`). Sitzung: Sightline (Cloud), Branch `claude/tender-goldberg-kijbub`.

## Anlass

Der Nutzer am 27.10.2026 will den Vorschlag von Gemini als eigenes Nebenprojekt ausprobieren: ein Kritiker vergleicht
Konzeptbild und Blender-Render und liefert JSON, ein Arbeiter ändert das Generator-Skript. Kritiker: „Nur API wie Gemini“. Der
einzige erlaubte API-Weg (`./ce api`) konnte nur Text senden.

## Umsetzung

- `ask --image <Pfad>` (mehrfach): PNG oder JPEG, als Base64-Bildblock **vor** dem Text der Nutzerrunde; dieselbe Nachricht geht an
  `messages/count_tokens` (Kostenschätzung und Reservierung zählen die Bilder mit) und an `messages`.
- Richtlinie: `max_images` (0–8, Standard 0 = aus) und `max_image_bytes` (≤ 3 750 000, Base64 bleibt unter 5 MB). Ohne Freigabe
  bricht `ask` mit Bildern vor Anmeldung und Netz ab.
- Prüfungen vor dem Netz: Kopfbytes (nur PNG/JPEG), Dateigröße, Kantenlänge aus PNG-IHDR bzw. JPEG-SOF (≤ 8000 px), Anzahl.
- `--dry-run` nennt zusätzlich `images`. Textanfragen schicken unverändert einen String.

## Was es nicht kann

- Kein Verkleinern: Bilder über der Grenze werden abgelehnt, nicht angepasst (das macht der Aufrufer, z. B. `ce_media`/`magick`).
- WebP/GIF nicht; PDFs nicht.
- Die Regeln in Nexogen (README › Automatische API-Delegation) schließen Bilder bis zur Freigabe weiter aus; die Freigabe für
  `cubeescape-critic` kommt mit Nexogen 1.20.33.
